# 📘 Ideal `.importignore` for FastImport

(Design Document — Dedup/Simplify Project)

FastImport is designed to help normal people organize personal content:

Images (photos, scans, artwork)

Videos (family events, phone recordings)

Audio recordings (voice memos, concerts, interviews)

Documents (PDFs, Word, Excel, scanned documents)

Everything else — installers, apps, caches, logs, system files, development artifacts, temporary files, and non‑personal media formats — should be ignored.

This document defines the ideal `.importignore` that reflects this philosophy.

## 1. Guiding Principles

### **✔ Only personal content should be imported**

Images, videos, audio recordings, and documents.

### **✔ Everything else should be ignored**

Executables, installers, system files, caches, logs, archives, disc images,
development artifacts, and non‑personal media formats.

### **✔ `.importignore` must be aggressive**  

FastImport should aggressively skip anything that is not personal content.
It is better to skip junk than to accidentally import gigabytes of irrelevant
files such as installers, caches, logs, system artifacts, development files,
archives, or non-personal media formats.

### **✔ `.importignore` must be stable**

It must work consistently across 20+ external disks with unpredictable content.

### **✔ `.importignore` must be readable and maintainable**

Clear categories, clear intent.

## 2. Categories of Files to Ignore

Below are the categories FastImport should ignore, with rationale and patterns.

### **❌ Category A — Executables & Installers**

These are never personal content.

```txt
*.exe
*.dll
*.msi
*.bat
*.cmd
*.sh
*.app
*.pkg
*.deb
*.rpm
```

### **❌ Category B — System / Cache / Temp Files**

Noise generated by operating systems and applications.

```txt
__pycache__/
*.tmp
*.cache
*.log
*.bak
*.old
Thumbs.db
.DS_Store
desktop.ini
```

### **❌ Category C — Development / Build Artifacts**

Not personal content.

```txt
*.o
*.obj
*.class
*.pyc
*.so
*.dylib
*.a
*.lib
*.pdb
*.ts
*.map
node_modules/
.git/
.svn/
```

### **❌ Category D — Non‑Personal Media Formats**

These formats are typically:

- downloaded
- ripped
- captured by DVRs
- part of Blu‑ray/DVD structures
- not personal recordings

```txt
*.wtv
*.ts
*.m2ts
*.vob
*.iso
*.img
*.bin
*.cue
VIDEO_TS/
AUDIO_TS/
```

### **❌ Category E — Archives & Compressed Files**

When FastImport encounters an archive (ZIP, 7z, RAR, ISO, TAR, etc.), the archive
is treated as a virtual folder. The archive is extracted into a temporary
working directory, filtered using `.importignore`, and all personal content is
imported into a destination folder named after the archive (minus extension),
preserving the internal directory structure of the archive.

Example:
source/personal/pictures/from_mom.zip → destination/personal/pictures/from_mom_zip/

The archive file itself is never imported, deduped, or stored. Only extracted
personal content is preserved.

#### Archive Extraction Folder Naming Rule

When FastImport extracts an archive (ZIP, 7z, RAR, ISO, TAR, etc.), the archive
is treated as a virtual folder. The extraction folder name is derived from the
archive filename by replacing the extension with an underscore version of the
extension.

Examples:
from_mom.zip → from_mom_zip/
backup_2020.iso → backup_2020_iso/
photos.7z → photos_7z/

This ensures:

- no collisions with existing folders,
- no collisions between different archive formats,
- predictable and stable destination paths,
- clear traceability of where extracted content came from.

### **❌ Category F — Large Non‑Personal Formats**

These can be huge and rarely contain personal content.

```txt
*.apk
*.ipa
*.crdownload
*.part
*.torrent
```

## 3. Categories of Files to Import (Implicit Allowlist)

FastImport should import:

### **✔ Images**

```txt
*.jpg
*.jpeg
*.png
*.heic
*.tiff
*.bmp
*.gif
```

### **✔ Videos**

```txt
*.mp4
*.mov
*.avi
*.mkv
*.mts
*.3gp
*.wmv
```

### **✔ Audio**

```txt
*.mp3
*.wav
*.aac
*.flac
*.m4a
*.ogg
```

### **✔ Documents**

```txt
*.pdf
*.doc
*.docx
*.xls
*.xlsx
*.ppt
*.pptx
*.txt
*.rtf
*.odt
```

> **Note**: These are not part of `.importignore` — they are the implicit allowlist.
